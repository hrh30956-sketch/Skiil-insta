# Sticky Lab Motion Studio — Claude Skill

## Install
In Claude: Customize → Skills → Add / Create skill → Upload a skill. Select the ZIP **as-is** (do not separately upload SKILL.md first). If your Claude interface uses a different menu label, look for Skills upload.
